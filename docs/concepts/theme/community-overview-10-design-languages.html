3 · Day-one circle — zero stateexpectation, not a failing scoreboard
Buttons, zero-state panel, and chips pick up each language's shape system — radius, borders, and shadows all come from tokens.

How this file works

Every visual decision routes through a token contract (--serif, --sans, --bg, --card, --green, --data, --r-card, --shadow-card…). The ten body[data-theme] blocks at the top of the stylesheet each override the full set, so a language is one CSS block — portable to the real app's theme layer. Heritage Sage #5B8268 anchors every palette; per-language label/action greens are darkened for AA on their backgrounds. Layout, copy, and behavior are byte-identical to community-overview-voice-fixes-v3.html. Press keys 1–9, 0 to switch languages.
