DESIGN LANGUAGES · HERITAGE SAGE

Ten design languages, one anchor

Every system below is anchored in Heritage Sage #5B8268 with a serif for titles and a sans for labels, data, and UI. None of them borrow the warm-cream / Fraunces / italic-accent / terracotta house style — backgrounds are neutral, green-tinted, white, or deep pine; accents stay in the green–slate–ink family. Each specimen card renders in its own tokens. See them applied in community-overview-10-design-languages.html and host-journey-10-design-languages.html.

Heritage Sage #5B8268 — the constant. Each language tints, deepens, or brightens it for AA contrast, but it stays recognizably the brand green.
