One palette, one font pair — the choice sheet

Seven palette candidates, each presented as a complete light + dark token set using the minimal vocabulary from #2441: background ramp, text ramp, border, primary + on-primary, accent, and the shared status colors. The favorites from PR #2440 (ink & sage, deep river, plum) were single-theme explorations — their counterpart themes here are synthesized and labeled as such. Two outliers (glacier, evergreen) are included for contrast. Every panel renders a marketing hero, an app-style card, buttons, body text, and status banners in its own tokens, with live-computed WCAG ratios for the load-bearing pairs. Pick a font pairing below — it re-renders everything.

Status colors are the current app set (#7A9B76 / #E8A661 / #D16B4E / #5A7A82), shown shared across themes per the issue. Heads-up on what the badges will show: warning fails (<3:1) on every light theme below — and on today’s shipped light theme too; success clears only the large-text bar. That’s pre-existing, not a defect of any candidate, and it’s the concrete evidence for giving status colors per-theme variants in tokens.json.
