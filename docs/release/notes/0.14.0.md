# Release 0.14.0

## New Features

- **Phone Login**: Added passwordless phone authentication via Firebase. Users
  can now sign up and log in with their phone number using SMS verification
  codes — no email or password required. Available on both iOS and Android
  ([#171](https://github.com/Type2Fun-Foundation/ripls/issues/171),
  [#1131](https://github.com/Type2Fun-Foundation/ripls/pull/1131))

## Bug Fixes

- **Experience Time Parsing**: Fixed timezone handling in AI-powered experience
  creation. The server was formatting the current time in UTC and parsing LLM
  responses in UTC, causing incorrect dates and times for users outside UTC.
  The client now sends the device's IANA timezone (e.g., "America/Denver") and
  the server uses it for all time calculations
  ([#990](https://github.com/Type2Fun-Foundation/ripls/issues/990),
  [#1132](https://github.com/Type2Fun-Foundation/ripls/pull/1132))

## Improvements

- **Structured Event Extraction**: When creating experiences from event URLs
  (Eventbrite, Meetup, Luma, AllEvents, etc.), the server now extracts dates,
  times, and locations directly from JSON-LD / schema.org markup embedded in
  the page. This provides 100% reliable date/time parsing for structured event
  pages, with LLM fallback for unstructured pages
  ([#990](https://github.com/Type2Fun-Foundation/ripls/issues/990))

- **Giveaway Status**: Updated the giveaway pill to show "Ready for pickup"
  after selecting a recipient, making the current state clearer
  ([#987](https://github.com/Type2Fun-Foundation/ripls/issues/987),
  [#1129](https://github.com/Type2Fun-Foundation/ripls/pull/1129))
