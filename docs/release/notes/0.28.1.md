# Release 0.28.1

Home screen freshness and CTA accuracy, nudge UI fixes, feedback screen
accessibility, and a calendar booking-limit overflow fix.

## Bug Fixes

- **Home Screen Staleness**: Items and events older than 14 days now age off
  the home feed. Live opportunities — events with open RSVPs, active requests,
  mid-handoff giveaways — stay visible regardless of age; expired or cancelled
  ones are removed within the horizon
  ([#2799](https://github.com/Type2Fun-Foundation/ripls/issues/2799))

- **Home Screen CTA Accuracy**: Event cards no longer invite you to Join when
  you're already going. Cards now reflect your actual participation — RSVP
  status, offers made, and gear already shared
  ([#2800](https://github.com/Type2Fun-Foundation/ripls/issues/2800))

- **Nested Nudge on Home**: The planning nudge was rendering inside the request
  nudge card on the home zero state. The two nudges now appear independently in
  their own frames
  ([#2796](https://github.com/Type2Fun-Foundation/ripls/issues/2796))

- **Calendar Nudge Text Cut Off**: Planning nudge copy was clipped on the
  calendar screen. Text now scales to fit its host frame, and the photo
  attribution icon is tappable
  ([#2801](https://github.com/Type2Fun-Foundation/ripls/issues/2801))

- **Feedback Screen Accessibility**: The in-app feedback entry is now a
  clearly-labelled row in the Settings menu (previously buried in a "help"
  item). The feedback sheet correctly inherits the glass token set, clearing
  the contrast failures visible in the prior layout
  ([#2797](https://github.com/Type2Fun-Foundation/ripls/issues/2797),
  [#2798](https://github.com/Type2Fun-Foundation/ripls/issues/2798),
  [#2806](https://github.com/Type2Fun-Foundation/ripls/issues/2806))

- **Nudge Vocabulary**: The nudge generation prompt was seeding the retired
  phrase "Plan an Experience." Nudge CTAs now use current vocabulary
  ([#2803](https://github.com/Type2Fun-Foundation/ripls/issues/2803))

- **State Region Code**: `extractStateCode` was always returning empty, causing
  state regions to be persisted without a USPS code. Location lookups that rely
  on the state code now work correctly
  ([#2802](https://github.com/Type2Fun-Foundation/ripls/issues/2802))

- **Booking Limit Overflow**: An integer overflow in `ClaimGearDays` allowed a
  booking to bypass the 30-day maximum. The arithmetic is corrected and the
  limit is consistently enforced
  ([#2815](https://github.com/Type2Fun-Foundation/ripls/pull/2815))

## Internal

- **Infrastructure Cost Savings**: ~$300/month reduction via health-checker
  result caching (15 min), switching Cloud Run to Direct VPC egress (removing
  Serverless VPC Access connectors), scaling the dev server to zero, automating
  Artifact Registry image cleanup, and switching prod Cloud SQL to ZONAL tier
  with an account-wide billing budget
  ([#2809](https://github.com/Type2Fun-Foundation/ripls/issues/2809))

- **Go Linter Wave 2**: 18+ additional linters enabled — `gosec`, `gocritic`,
  `stylecheck`, `gofmt`/`gofumpt`/`goimports`, `godot`, `nolintlint`,
  `unparam` — plus two resource leaks and a swallowed database error fixed by
  the new rules; all gates enforced in CI with pinned versions
  ([#1611](https://github.com/Type2Fun-Foundation/ripls/issues/1611))

- **Android/JDK Upgrade**: Baked JDK bumped from 17 to 25 and AGP updated to
  9.3.1, unblocking bundled-lint improvements on Android builds
  ([#2787](https://github.com/Type2Fun-Foundation/ripls/issues/2787))
