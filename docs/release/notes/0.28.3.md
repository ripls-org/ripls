# Release 0.28.3

Chat locale correctness and internal tech-debt cleanup.

## Bug Fixes

- **Chat Messages Now Locale-Aware**: System chat messages were embedding
  English text directly into template parameters — Spanish viewers saw strings
  like "Someone confirmó la hora: Wed, Jan 1 · 9:00 AM" rather than fully
  localized output. Unknown actors are now represented by an empty param that
  the client substitutes with the locale-appropriate word for "Someone", and
  scheduled-time changes travel as a raw unix timestamp + UTC offset so the
  client formats the time in the viewer's locale
  ([#2844](https://github.com/Type2Fun-Foundation/ripls/issues/2844))

## Internal

- **RSVP Field Cleanup**: The legacy string-typed `intention` and `attended`
  fields on `ExperienceRSVP` are removed; the integer enum columns (`intention_enum`,
  `attended_enum`) are renamed into their place with a boot-time migration. Eight
  production query sites that were passing string values — which would have caused
  PostgreSQL errors once the columns became INTEGER — are corrected. Net −381 lines
  ([#2832](https://github.com/Type2Fun-Foundation/ripls/issues/2832))

- **Post-Soak Removals**: `GetPortfolioInboxView` (replaced in v0.28.2 by
  `GetDirectoryPeople`) and the server-rendered copy fields deprecated in #2827
  are deleted after their client migrations shipped in v0.28.2. Net −1,367 lines.
  The proto soak policy is tightened from "two release cycles" to "one shipped
  release + ~24 h" — the interval that actually covers the rollout overlap
  ([#2834](https://github.com/Type2Fun-Foundation/ripls/issues/2834),
  [#2835](https://github.com/Type2Fun-Foundation/ripls/issues/2835))
