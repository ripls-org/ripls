# Release 0.9.1

A focused patch release with UX improvements to requests and loans, plus
cleanup from the 0.9.0 launch.

## UX Improvements

- **Streamlined Request Fulfillment**: Removed the two-phase summary modal when
  marking a request fulfilled — owners now go directly to the impact metrics
  screen. The server already sends a FULFILLED system message, making the
  client-side summary redundant
  ([#992](https://github.com/Type2Fun-Foundation/ripls/issues/992),
  [#1001](https://github.com/Type2Fun-Foundation/ripls/pull/1001))
- **Withdraw Offer from Requests**: Helpers can now withdraw their offer
  directly from the request pill menu, without needing to navigate into the
  conversation
  ([#991](https://github.com/Type2Fun-Foundation/ripls/issues/991),
  [#997](https://github.com/Type2Fun-Foundation/ripls/pull/997))
- **Pickup Modal Text Fix**: The arrange pickup modal now correctly shows
  owner-perspective duration text (e.g., "How long do you want to lend it?")
  instead of borrower-perspective text
  ([#988](https://github.com/Type2Fun-Foundation/ripls/issues/988),
  [#998](https://github.com/Type2Fun-Foundation/ripls/pull/998))

## Bug Fixes

- Fixed redundant success toast when withdrawing an offer from a request
  ([#997](https://github.com/Type2Fun-Foundation/ripls/pull/997))
- Fixed `markFulfilled` call in request management card not passing the correct
  arguments
  ([#1001](https://github.com/Type2Fun-Foundation/ripls/pull/1001))

## Infrastructure

- Removed conversation topic migration job that had already run in production
  ([#996](https://github.com/Type2Fun-Foundation/ripls/pull/996))
- Downgraded feed "not found in batch" logs from Error to Warn for soft-deleted
  items — expected behavior, not a system error
  ([#995](https://github.com/Type2Fun-Foundation/ripls/pull/995))
