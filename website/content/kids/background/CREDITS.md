# School-and-team page — background image credits

Backgrounds for `host-journey-school-and-team.html`, loaded from this folder.

This page previously pointed at the shared `images-forward/` pool (which serves
~15 other preview pages with a generic crew/outdoors set — backcountry skiing,
barn raising, construction crews). Those were a poor match for a kids / parents
/ school-and-team page, so this page now loads from its own folder and the
images are curated to each section's message. Files are named for each
section's `data-bg` number. Unsplash, free for commercial use, attribution
required. Full machine-readable attribution is in `attributions.json`.

On-page `photo-credit` lines appear on the five full-bleed editorial sections
(01, 02, 03, 04, 07), matching the page's existing design. The feature sections
(06, 09, 10, 11, 13) and the trust section (05) carry their darkened background
behind a phone frame / body copy and are credited here instead.
