Release 0.10.0

April 6, 2026

Single player mode, iOS notification fixes, and a batch of community-reported bug fixes.

Features

  • Single Player Mode: Record past experiences, loans, giveaways, and requests — complete with shadow users for non-registered participants, completion modals showing impact estimates, and a manage members screen in community settings (#1043, #1046)
  • Active Participant Counts: The manage button now shows the number of people actively involved in each item (#1016)
  • Giveaways in Feed: Giveaways now always appear in the community feed, matching the behavior of experiences and help requests (#1015)

Bug Fixes

  • iOS Push Notifications: Fixed three independent issues that broke iOS notifications — FCM not initializing after fresh login, debug/profile builds using wrong bundle ID, and stale device tokens never being evicted (#1027, #1035, #1039)
  • Chat Notification Deep Links: Chat notifications now navigate directly to the correct chat tab instead of getting lost during navigation (#1036, #1041)
  • Gear from URL: Improved success rate from 61% to 71% of retailer sites with browser-like User-Agent, plus clear localized error messages when a site can’t be scraped (#1002, #1010)
  • Auto-Capitalization: Fixed missing auto-capitalization on feedback sheet text fields (#1038, #1042)
  • Giveaway Display: Profile screen now correctly shows active giveaways instead of mislabeling them as loans (#1013, #1019)
  • User Screen Metrics: Other users’ profile screens now match the portfolio metrics layout (#1009, #1018)
  • Onboarding Disabled: Removed onboarding screens during closed beta — all users enter directly into their community (#983, #1014)
