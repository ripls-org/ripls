Release 0.19.2


New Features

- Leave or delete your community: Community owners can now choose between transferring ownership and leaving, or deleting the community outright, via a new Danger Zone modal in Settings. Non-owners get a straightforward Leave action with an ownership-handoff picker when they are the last admin (#1718, #1719)

- Restore a deleted community: Members listed in a community’s deleted snapshot can now restore it from Settings → Communities. A countdown badge shows how many days are left in the 30-day restore window (#1717)

- Rejoin a community you recently left: Settings → Communities now shows a “recently left” section. Each entry displays the time elapsed since you left, how many days remain in the rejoin window, and a single tap to rejoin (#1721, #1723)

Bug Fixes

- Close Request modal lacked Cancel and Unshare options: Tapping the close button on a request only showed “Delete Permanently” — the Cancel and Unshare actions were present in the UI but their callbacks weren’t wired up. All three options now work correctly (#1726)

- Info and Watch icons blocked the Save button during editing: The info and watch icons stayed visible in gear, event, and request app bars while in edit mode, overlapping the Save button and making it hard to tap. Both icons are now hidden during edits (#1727)

- Community creation camera mode had no shutter button: In community creation, switching to camera mode showed the live preview but provided no way to take a photo — tapping “Generate” silently did nothing. The shutter-on-generate logic now matches the gear, event, and request creation flows (#1662)

- Create Request failed for users in All Circles or a single community: The request creation flow required an explicitly selected community, so users who had All Circles active (or belonged to only one community) hit a dead-end snackbar. The flow now auto-selects the single community when there is only one, and opens the community picker in the multi-community case (#1735)

- Spurious HTTP/2 error logged on normal stream close: The community event stream logged a WARNING-level “http/2 stream closed with error code INTERNAL_ERROR (0x2)” on every 120-second lifetime cap close — a normal server-side timeout, not a real error. The log level is now Info (#1734)

- Six Spanish strings were untranslated: Several strings added since the last translation pass were missing their Spanish translations and fell back to English for Spanish-locale users. All six are now translated
