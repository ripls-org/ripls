Release 0.23.1

May 29, 2026

Bug Fixes

  • Google Maps missing from production builds: Prod iOS and Android builds shipped without the Google Maps API key after the #2188 Maps migration, causing blank, non-functional map tiles on all production devices. The release pipeline now fetches the Maps key from Secret Manager and injects it at build time. A Gradle guard prevents any signed release APK or App Bundle from being assembled without the key, and the iOS Fastfile lane hard-fails if the key is absent. A follow-up tightens the Gradle guard to fire only on keystore-configured (fastlane) builds, so debug signing and R8/ProGuard verification builds continue to work without GCP credentials (#2242)
