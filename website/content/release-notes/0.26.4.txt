Release 0.26.4


Event calendar fix and infrastructure improvements.

Bug Fixes

- Events Missing from Community Calendar: Fixed events appearing in the inbox calendar but not in a community’s calendar view. Each event belongs to both a real community and an internal ad-hoc backing community; a nondeterministic community-ID pick frequently resolved to the ad-hoc one, causing the event to be excluded from the community calendar filter. Named communities are now always preferred. The server also propagates the full community-ID set in HomeUpNextEntry so the client can match on any valid community (#2675, #2677)

- Push Notification Broadcast Race: Fixed a race where member-broadcast push notifications could be sent to a stale or inflated audience when a new item was published concurrently with membership changes. The broadcast audience is now snapshotted at publish time, making notification counts deterministic (#2657)

Internal

- Flutter Web WASM: The web app bundle is now built with --wasm and served with Accept-Encoding negotiation (brotli + gzip precompressed), improving Dart runtime performance for web users (#2119)

- AI Prompt Efficiency: Gen* prompts (image, webpage, text) rewritten for token efficiency, reducing per-request token cost while maintaining output quality. Proper-noun leakage in search_keywords also addressed (#1265, #1209)

- Activity Digest Enhancements: Admin digest emails now categorize community actions, measure true daily-active users (replacing refresh-token-churn counting), and identify ad-hoc vs named communities in the community breakdown (#2665)

- Go File-Size Gate: Added a 1,000-line hard CI limit for Go server files; oversized files split into focused sibling files by concern. Completed the ConversationId/CommunityId deprecation migration (#1424, #1332)
