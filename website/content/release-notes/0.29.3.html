Release 0.29.3

August 13, 2026

One bug fix: system-generated notifications now render with real text instead of blank name slots.

Bug Fixes

  • Notification Copy No Longer Blank: Eight system-generated notification types — event reminders, close prompts, nudges, and others — were sending off-app messages that read " posted an update in " with two empty name slots and a dangling preposition. The same strings appeared as SMS messages and email subjects. Root cause: those eight types were not mapped in the off-app copy table, so all fell through to a default template that expects an actor name and a community name neither system jobs nor these payloads ever supply. The fix maps every notification kind to its own copy, adds name-slot fallbacks ("Someone", "your community") so a missing lookup produces a readable sentence rather than blanks, and adds a build-time gate (TestEveryNotificationEventTypeHasCopy) that fails if any future event type reaches production without copy. Push, SMS, and email now all draw from a single per-kind template instead of four divergent copies (#2896)
