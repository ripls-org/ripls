Release 0.33.0


Sharing an item with someone on Ripls now actually tells them, and the shared “That’s everything” card finally loads its image for everyone. Prod completes its move to self-hosted hardware, and the project’s agent tooling is ported to a new dispatch bridge ahead of going public.

New Features

- Notifications When an Item Is Shared With You: Sharing an item with someone already on Ripls used to add them to the item’s community and tell them nothing: no push, no text, no email. Recipients now get a notification naming who shared what, with copy that distinguishes an item to borrow or claim, an event, and a request for help (English and Spanish). Only the people a share newly adds are notified, so widening an item’s audience never re-notifies existing members, and the recipient’s community list, portfolio, and feed refresh immediately so the item appears without a manual refresh (#3106, #3109)

- Prod Runs on Self-Hosted Infrastructure: Production was cut over from Cloud Run and Cloud SQL to the self-hosted mimir stack (freeze to flip took 23 seconds with an identical data copy). server.ripls.org and ripls.app now point at mimir, monitoring reads the mimir stack’s logs and probes the public health endpoint, and a new Server Logs Absent alert covers missing log shipping (#3078, #3102)

- New ripls.org Home Page: The website’s front door is rewritten for the Ripls Foundation, leading with mission, principles, and story. Each branch preview on staging now gets its own nginx routing, so previews no longer overwrite each other’s root page (#2895, #2898, #3114)

- Open-Source Readiness for Contributors: Every agent and Renovate workflow now refuses fork PRs, self-hosted runners register at the org level, and the agent workflows (claude_*, release cut) are ported to a new agent bridge with a @claude-bridge trigger, retiring the personal access token they previously needed. The export harness and governance files completed (#2966, #2967) are now closed out (#3172, #3174, #3175, #3185, #3190)

Bug Fixes

- Shared Nudge Images Load for Everyone: The shared “That’s everything” card’s stock image was owned by whichever user’s feed load created it, so every other viewer got a permission error and a broken image. Stock imagery is now owned by the system user and readable by all. Existing broken cards are replaced at the next daily rollover (#3105, #3108)

- Story Community Index Created: The idx_story_community index targeted "story" instead of "Story" and silently failed on every boot, so community story lookups were always sequential scans. The statement is fixed and a test now asserts every schema index exists after initialization (#3088, #3107)

- False “Database Pool Saturation” Alerts: Pool utilization was measured against the connections currently open rather than the pool’s limit, so a single query on an idle server read as 100%. It is now measured against the configured maximum (#3103)

- Docker Build Check Fetches the Real Model: The Docker build check now fetches Git LFS files, so the image contains the actual embedding model rather than an LFS pointer (#3153)

- Flaky Auto-Fulfill Test: The request hand-off test now waits for the fulfillment event instead of racing it (#3113)

Maintenance

- Routine dependency updates: Flutter 3.47.7, Go 1.27.2, Buf 1.74.0, Playwright 1.64.1, ESLint 10.13.0, typescript-eslint 8.71.2, Gradle 9.8.0, Kotlin Android plugin 2.4.21, Android Gradle plugin 9.4.1, golangci-lint 2.14.0, gofumpt 0.12.0, Terraform Cloudflare provider 5.26.0, and Go module updates.
- Documentation: anyone who verifies a doc against its code may now advance its freshness stamp (#3112).
