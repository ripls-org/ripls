Release 0.33.1


A maintenance release, and the first one built and shipped from the project’s new home. Reminder and nudge notifications now arrive in your language, the app’s networking libraries are current, and the last of the code kept for retired services is gone.

New Features

- Reminders and Nudges in Your Language: Scheduled event reminders and organizer nudges sent their push notification in English even when texts and emails already followed your language preference. A Spanish-language member now gets these pushes in Spanish too (#3276, #3283)

- One Public Repository, Developed in the Open: Development, CI, deploys and releases moved from a private GitHub repository to a single public repository on the project’s own Forgejo instance, with github.com/ripls-org/ripls as a mirror. The deploy and release pipelines, the website, the runner fleet and the planning notes are all published, scrubbed of personal data, and every change is checked against a private denylist so it stays that way. CONTRIBUTING.md says how to take part (#3228, #3293)

Bug Fixes

- No More Pages for a Normal Deploy: The uptime alert paged whenever a single probe landed in the few seconds a deploy takes to restart the server, which was about four deploys in ten. It now fires only when two checker locations fail at once for a minute (#3317)

- Feedback and Alerts Land in the New Tracker: In-app feedback and crash and monitoring alerts are filed in a private tracker on the new forge instead of GitHub. Prod’s feedback switches over with this release (#3318, #3321, #3323)

Under the Hood

- Current Networking Libraries in the App: The Flutter client moved to connectrpc 2 and protobuf 6, lifting a long-standing hold on dependency updates. Nothing changes on the wire (#3304, #3305)

- Retired Code Removed: Mapbox, unused since the move to Google Maps, is gone from the server and the app, and so are three AI summary endpoints that no released app has called for three versions. Their field numbers are reserved (#3254, #3278, #3282)

- Cloud Run and Cloud SQL Decommissioned: The managed services the servers left in September were deleted; everything runs on the project’s own hardware (#3079, #3257)

- CI on Forgejo Actions: Tests, deploys and releases run on Forgejo Actions on the project’s own runners. Cloud Functions deploy with a short-lived identity token rather than a stored key, a server-side hook refuses any push that contains a secret, and the coding agent’s workflows run from Forgejo events. The Mac that builds iOS moved to Xcode 27.2, JDK 25, Node 24 and Ruby 4.0.9 (#3293)

- Dependency Updates: Twenty routine dependency updates.

Issue and pull request numbers above are from the private repository the project was developed in until this release. Its tracker was not published.
