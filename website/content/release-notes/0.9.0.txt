Release 0.9.0 — Private Beta Launch


This is the official Ripls Private Beta launch. After months of closed testing, iteration, and hardening, Ripls is opening up to our first wave of private beta users. This release represents a major milestone: a polished, stable, and feature-complete foundation for community sharing of goods and experiences.

Highlights

- Private Beta Ready: Comprehensive UX polish, bug fixes, and stability improvements across every workflow — loans, giveaways, requests, and experiences are all production-ready for real communities.
- Notification Deep Linking: All notifications now navigate directly to the relevant item detail screen, not just a generic chat view (#977, #962, #978, #980)
- Nudge Cards: AI-generated nudge cards in the feed encourage engagement — suggesting items to share, experiences to plan, or requests to make (#935)
- Feed Freshness: Smart feed expiration based on view count and time since last activity, so the feed always feels current and relevant
- Expanded Metrics: Community and personal impact metrics with leaderboards, charts, and detailed drill-down views (#975, #949, #952)

New Features

- Item Link Previews: Sharing a Ripls link on social media or messaging apps now shows rich OG metadata with item-specific titles, descriptions, and thumbnail images (#955, #953)
- Pickup Coordination: Arrange pickup times directly within loan and giveaway conversations with date/time proposals and notifications
- Time Polls for Experiences: Organizers can propose multiple times and collect votes from attendees, with a “none work for me” option
- Multi-Model AI: Switched to Haiku as the primary AI provider with Gemini fallback for faster, more cost-effective gear recognition (#918)

UX Improvements

- Loan Workflow Polish: State-aware menus, responsive pill labels by queue position, visual interest counts, and streamlined pickup modals (#974, #960)
- Giveaway Workflow Polish: Simplified recipient picker, state-aware menus, pickup notifications, and consistent title casing (#968, #959)
- Request Workflow Polish: Improved offer management, action button updates on withdrawal, and cross-community sharing fixes (#971, #965)
- Experience Workflow Polish: Fixed completion flow, RSVP updates, and cross-community leakage (#969, #985, #984, #967)
- Consolidated Menus: Consistent workflow-driven menus across all item types with grayed-out completed steps (#938, #939)
- Community Metrics Landing: Redesigned community metrics screen (#982)
- Waitlist Improvements: Expanded signup fields and refreshed landing page messaging (#948)

Bug Fixes

- Fixed experience completion requiring a summary and not allowing direct completion from active state (#984)
- Fixed cross-community RSVP leakage (#665, #945)
- Fixed chat notification routing to wrong screen (#962)
- Fixed system messages not appearing until a user message was sent (#947)
- Fixed dark mode contrast in form fields, modals, and RSVP buttons (#936, #865, #932)
- Fixed EXIF rotation on OG images when shared via Signal (#958)
- Fixed Pexels rate limiting for stock video generation (#929)
- Fixed Android layout crash in action bars (#853, #867)
- Fixed video crash when viewing details (#934)

Infrastructure

- Patrol E2E Test Suite: Full end-to-end test coverage for all workflow types — loans, giveaways, requests, and experiences — with screen recording, multi-user coordination, and postcondition verification (#866)
- Equity System Removal: Removed the community equity system in favor of impact metrics (#874)
- Conversation Topic Refactor: Consolidated conversation topic handling into a dedicated proto type (#872)
