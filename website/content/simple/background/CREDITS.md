# "Less stuff. More life." page — background image credits

Backgrounds for the conservation/ page (`index.html` and
`host-journey-conservation.html` — same content, both load from this folder).
The folder previously held copies of the generic crew/outdoors pool
(`images-forward`), which didn't match this page's borrow-don't-buy /
neighborhood-sharing message, so these were curated to each section. Files are
named for each section's `data-bg` number. Unsplash, free for commercial use,
attribution required. Machine-readable attribution is in `attributions.json`.

On-page `photo-credit` lines appear on the five full-bleed editorial sections
(01, 02, 03, 04, 07). The feature sections (06, 09, 10, 11, 13) carry their
darkened background behind a phone frame and are credited here instead.
